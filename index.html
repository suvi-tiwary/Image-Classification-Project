How to use

  1. Allow camera access when prompted.
  2. Click Capture Photo to freeze a frame from the webcam.
  3. Click Check Mask to see if the system detects mask usage.

This demo uses a simple placeholder detection heuristic. For a production system, connect the captured image to a trained mask detection model or backend API.
