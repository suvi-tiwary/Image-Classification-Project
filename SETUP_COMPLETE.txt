📋 FIRST TIME SETUP:

1. Open terminal/command prompt in this folder

2. Install dependencies:
   pip install -r requirements.txt

3. Run the app:
   streamlit run app.py

4. Your browser will open to http://localhost:8501

═══════════════════════════════════════════════════════════════════════════

🎯 USING THE WEB APP:

1. Upload an image or take a photo
2. The AI will classify: "With Mask" or "Without Mask"
3. See confidence percentage and detailed breakdown
4. Adjust threshold if needed (sidebar settings)
5. Download the classification report

═══════════════════════════════════════════════════════════════════════════

🔧 TRAINING YOUR OWN MODEL:

If you have a dataset, structure it as:
   data/
   ├── with_mask/      (your mask images)
   └── without_mask/   (your non-mask images)

Then run:
   python train_model.py

This creates: image_classification_model.h5

Restart the app to use your trained model!

💡 TIPS:

• First prediction takes ~5-10 seconds (model loading)
• Subsequent predictions are very fast (<1 second)
• Use clear, well-lit images for best results
• Adjust confidence threshold based on your needs:
  - Lower (0.3-0.5): More lenient
  - Higher (0.6-0.8): More strict
• Save your trained model (.h5 file) for reuse
